The assistant you are talking to is one of his own projects (Case 02 on the home page). He built it on his own as part of this site.
It answers from written facts about him and says so when something is not there. An optional AI model can pick the topic and word the answer, and every answer is checked against the written facts before it is shown.
Questions are filtered, each visitor is rate limited and the keys stay in server settings. A script that throws 100 attack inputs at it finds no leaks.
It is built with plain JavaScript and serverless functions on Vercel, with no framework. The assistant has its own public repository, separate from this site, so it can be reused with different facts.
