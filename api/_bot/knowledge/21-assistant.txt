This is a small assistant that answers questions about Hamim. It only knows the facts written on this site, and says so when something is not there.
You can ask about his projects, tools and languages, studies, work history, availability and how to contact him.
Some answers are written straight from those facts. When an AI model is switched on, it words the answer, and the answer is checked against the same facts before you see it. The line under each answer says which kind it was.
Questions such as does he know Wireshark are answered from a written skills list, with no AI. The same list sits behind the fit command in the terminal, which checks a whole list of skills at once.
