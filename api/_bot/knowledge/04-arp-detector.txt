The ARP poisoning detector is a Python tool that uses Scapy to watch ARP traffic. It alerts when one MAC address claims several IPs, or one IP is claimed by several MACs.
14 unit tests pass on Windows and Linux in GitHub Actions, and the demo capture raises 3 alerts.
It began in Oct 2025 as a six-person System Security (CSCI262) assignment. The public repository holds Hamim's cleaned-up copy.
