LayerLens is his own project (Nov 2026): a small Node.js web app that shows a visitor what their browser and connection reveal, and where each detail came from. It has a written threat model and 62 automated tests.
It is not deployed. The optional TLS fingerprint diagnostic has not been run against real TLS traffic, reverse DNS has only run against a local test DNS server, and no independent security audit has been done.
