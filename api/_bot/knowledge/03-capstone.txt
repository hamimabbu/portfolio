Hamim built the file-upload security of a team capstone for Micromax Technology (Mar 2026 to present): a scanner that checks file signatures and inspects PDFs, ZIP archives, images and documents.
He also added upload rate limiting, an audit page for blocked files, real-time alerts and role-based permissions.
Backend integration tests and Cypress tests cover it, and he has 30+ commits in the team repository. Stack: Node.js, Express, MongoDB, React, Socket.IO.
