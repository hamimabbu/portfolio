The Active Directory home lab (Jul 2026 to present) is a Windows domain called marvel.local in VirtualBox, built while following a guided course. It has a Windows Server 2022 domain controller and a Windows 11 client joined to it.
Hamim set up Active Directory Domain Services, Certificate Services, static IPs, an SMB share, Group Policy and a service account with an SPN for Kerberoasting.
Next he plans to connect Kali and run LLMNR poisoning, SMB relay and Kerberoasting, then write up what each one leaves in the logs. The domain is built and documented on GitHub, but there are no attack results yet.
