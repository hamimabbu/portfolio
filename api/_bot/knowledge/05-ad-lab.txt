The Active Directory home lab (Jul 2026 to present) is a Windows domain, marvel.local, in VirtualBox, built while following a guided course.
It has a Windows Server 2022 domain controller and a Windows 11 client, with Group Policy, Certificate Services and a service account for Kerberoasting.
The attacks come next (LLMNR poisoning, SMB relay, Kerberoasting), so there are no attack results yet.
