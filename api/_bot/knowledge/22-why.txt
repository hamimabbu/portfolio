These are the points the site backs up with projects.
He works on both sides of security. The upload scanner blocks risky files and the ARP detector raises alerts on forged network traffic. The Active Directory lab is built so he can practise the attacks that tools like these have to catch. Those attacks come next.
He tests his work. LayerLens has 62 automated tests that run on Node.js 22 and 24 in GitHub Actions, the ARP detector has 14 passing unit tests, TalentMatch Pro has 86 end-to-end tests and 14 backend unit tests, and the capstone has backend integration tests and Cypress end-to-end tests.
He says what is not finished. The Active Directory lab page says there are no attack results yet, and the upload scanner, ARP detector and LayerLens pages list what those tools cannot do.
He covers more than one area. He has built Node.js and Spring Boot systems, and he has set up a Windows Server 2022 domain with Active Directory.
He studies full time and works part-time at the same time.
