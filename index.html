Site assistant: a chatbot that sticks to the facts

2026. Independent project. It is the chat at the top of this page.

Problem
A chatbot on a personal site can invent facts about me or be talked into saying other things, so a visitor cannot trust it unless every answer is checked.
What I built
A chat that answers from text files of written facts and says so when something is not there. An optional AI model can pick the topic and word the answer. Questions are filtered, every answer is checked against the written facts before it is shown, and each visitor is rate limited.
Result
A script that throws 100 attack inputs at it finds no leaks, and the unit tests pass. It runs as serverless functions on Vercel with no framework. The code is its own public repository, so it can be reused on another site.
  • Node.js
  • JavaScript
  • Serverless functions
  • Vercel

CASE 03

LayerLens: what a browser and a connection reveal

Nov 2026. Independent project. Relevant to: application security, backend developer

Problem
A website can read many details about a visitor's browser and connection, and a tool that shows them back is easy to misuse, for example to probe other networks.
What it does
Shows what a browser and connection reveal, with the source and limits of every result. Lookups run only after the operator switches a source on and the visitor approves it, and a request cannot name a target.
Result
62 automated tests pass on Node.js 22 and 24 in GitHub Actions. A written threat model lists nine risks with the control for each. It is not deployed, and the optional TLS fingerprint diagnostic has not been run against real TLS traffic.
  • Application security
  • Node.js
  • JavaScript
  • Docker
  • GitHub Actions

Active Directory home lab

Jul 2026 to present. Relevant to: systems administrator, IT support

Problem
Many companies run on Windows domains. I wanted to build one, attack it, and learn what each attack looks like from the defender's side.
What I did
Built a domain called marvel.local in VirtualBox while following a guided course: a Windows Server 2022 domain controller and a Windows 11 client, with Certificate Services, Group Policy, an SMB share and a service account for Kerberoasting.
Result
The domain is built and documented on GitHub. The attacks come next (LLMNR poisoning, SMB relay, Kerberoasting), so there are no attack results yet.
